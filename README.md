# Minecraft Access

[![Weblate translation status badge](https://hosted.weblate.org/widget/minecraft-access/svg-badge.svg)][Weblate]

Minecraft Access is a [Minecraft] mod that specifically helps visually impaired players play Minecraft.
It is an integration and replacement for [a series of previous mods][accessible-minecraft].
This mod primarily borrows the help of a screen reader to describe (narrate) the game interface,
and incorporates sound cues to provide orientation perception in this 3D world.
Currently, this mod [has enough features][faq-features] to help visually impaired players play the game normally.

Whenever the mod's code is updated, or whenever we need an upcoming feature someone contributed to be tested,
a build will be automatically published in the [Playability Discord server][discord] first to allow for testing,
after enough feedback has been gathered, or no serious bugs have been reported in the build,
the version will be released on [Modrinth], [CurseForge], and [GitHub].

## Contributions

Any type of contribution is welcome:

* Be one of the first to try out new versions and help us find bugs and issues.
* Improve this mod's documentation for better readability and accessibility.
* Help us translate this mod into other languages via [Weblate].
* Create more text or video tutorials about how to play the game with this mod ([examples][gameplay]).
* Make sound effects for this mod.
